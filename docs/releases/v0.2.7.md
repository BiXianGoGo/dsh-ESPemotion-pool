# 0.2.7 — 先把状态分清，再谈形状

这一版不增加新入口，只把「这一轮到底是什么状态、像不像以前那个形状、该不该给它名字」这条链补齐。

## 新增

- **四态分层**：基线 / 波动 / 趋势 / 跳变。跳变单独标，不进形状分类；只有趋势进形状与命名。
- **门槛自标定**：按池内最近 2000 轮的分位算（基线 30% / 趋势 20% / 跳变 5%），变化超过 0.03 才落盘；样本不够用种子先验，卡片显示校准进度。
- **形状距离**：折角、折数、折点间距 + DTW；权重按池内逆标准差，向种子收缩。
- **新尺**：先减随机基线（0.617），再拉伸到 0–1；三层归属 0.88 / 0.55。
- **三问八片**：有方向 → 正 / 负 → 回落；无方向 → 抖得大 → 折返。名字挂树丛，不挂叶。
- **三轴定名**：E / S / P 各取末 8 点，三轴距离平均；自报精确名优先。
- **定名只跑趋势**：基线 / 波动 / 跳变不起名、不进候选、不写原型。
- **种子冷启动**：随包带 500 条去标识数字曲线（`assets/seed-500.json`），按 `n/(n+500)` 收缩；自己的数据逐渐盖过种子。
- **分享包 v2**：带 500 条种子 + 顶层 `种子哈希`；v1 包仍可导入，本地已有不同种子时保留本地。
- **名字库卡片**：待命名页默认收起，展开 2 列，名字 / 原型数 / 代表曲线 / 改名；旧 363 条折成一行，不再铺满屏。
- **卡片**：状态徽标、门槛行、校准进度、8 片分布、待命名候选区。

## 升级

0.2.6 → 0.2.7 直接覆盖插件目录并重启 DSH。旧池、旧事件、旧命名表不动；第一次启动会读种子，按已有轮数混合。

## 测试

全量测试见仓库 `tests/`；0.2.7 收口时 **797 条全绿**，`lib/index.js`、`lib/calib.js`、`assets/widget.js` 三个 `node --check` 均为 0。

## 已知边界

- 旧轮画像没有 `片` 字段，0.2.7 不回填历史；只有重启后的新趋势轮才会落片。
- 待命名 363 条按主人要求延后处理，不在这版清；旧条无曲线，页面只作计数。
- 分享包 v2 只多带种子曲线；权重 / 门槛 / 基线 / 原型仍不带。

## 数据与隐私

- 不带作者的池、会话、事件、思考轨迹、名字。
- 种子只有 E / S / P 数字，没有原话、时间、会话 id、名字。
- 插件不联网。
