# 0.2.6 — 分享架构（存档）

> 这是 0.2.7 之前的存档版本。安装、数据口径与当前版本请以 [0.2.7](v0.2.7.md) 为准。

0.2.6 的主题是「把情绪叫什么的形状，和这一轮发生了什么分开」。

## 新增

- **命名表独立**：名字、形状区间、元数据放在 `情绪池-命名表.json`，不跟池、会话、事件混在一起。
- **分享包 v1**：只带命名架构（名字 + 形状区间）；不带池、会话、事件、思考轨迹、权重、门槛、基线、原型。
- **匿名导出**：导出的名字做匿名化；默认不带依据，强制匿名时一定不带。
- **导入预演**：新增 / 撞名 / 版本不合 / 解析失败先列出来，确认后才写主表。
- **三轴情绪池**：E / S / P 三条曲线，思考轨迹打点，事件流与回落。

## 测试

0.2.6 收口时全量测试全绿；具体数量以当时的 `CHANGELOG.md` 为准。
