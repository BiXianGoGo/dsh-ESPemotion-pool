# 情绪池 · 使用说明（给人看的）

## 这是什么

它会给聊天里的 AI 记一份「情绪状态」，并且**看得出来是什么样的情绪、因为什么**。

三根轴，每根 −100 到 +100：

| 轴 | 往负走 | 往正走 |
|---|---|---|
| **E** 关系 | 向对方索取、要求、占有 | 向对方让渡、崇拜、贬低自己 |
| **S** 踏实 | 判断悬着、对人有坏影响 | 判断准、对人好 |
| **P** 痛感 | 需要找补、想回避、被否 | 顺着、被认可、轻快 |

不用记符号。看卡片时只要读一句话：**「E 在往哪边、S 稳不稳、P 疼不疼」**。

---

## 卡片怎么用

插件卡片有五页，右上角圆点或左右箭头翻页：

1. **三轴**：当前三个值 + 折线。折线可以**滚轮左右拖**看历史；鼠标停在折点上会出现那一刻的原话、第几段、三轴读数。默认跟着最新走，往左拖了会显示「已离开最新 · 按 End 回最新」。
2. **本轮观测**：这一轮到底怎么算出来的——分了几段、判为谁、双轨取了谁、K 值多少、敏感/适应多少。分组可折叠。
3. **事件**：每一次推动轴值的事件，带段号、为谁、三轴变化、来源、原话。
4. **情绪待命名确认页**：模型给出待命名的情绪，你确认、丢弃或改名。
5. **设置**：所有参数、池管理、说明书入口。

---

## 池：一个池 = 一段关系

- 一个池可以装**一个或多个会话**（比如「聊天间」和「策划间」算同一个人，可以并进一个池）。
- 池由你建、你改名、你删。**不自动生成**。
- 没归进池的会话不统计、不注入、也不会出现在卡片页签里。

**怎么建**：设置页 → 数据源 → 填池名 → 在「会话」里选择要装进来的会话 → 选中即生效。
**怎么删**：同一行点「删除」，会问你「只从列表移除」还是「连池文件一起删」。事件不会被删。

## 常见问题

**数值自己往下掉？**
会。没有新对话时，情绪会按时间往 0 回落（这是设计），不是出 bug。

**某一轮涨得特别猛？**
单轴单轮最多 0.30（±100 制就是 30 点），超过会被截断，事件里会写「夹断」。

**为什么同一句话有时判得不一样？**
两轨判断（一个带上下文的、一个不带记忆的克隆）会分歧；分歧在阈值内取加权中点，超过阈值按各自的可信度 K 决定听谁的。

**K 是什么？**
这条判断「说话算不算数」的分数，0.5~1.0。判错多的会降权，但记录不删。

**想让 AI 换个说法描述自己的情绪？**
它每轮会收到一行自述，格式固定；说明文档在 `情绪池-模型说明书.md`，卡片设置页可以一键打开。

## 出问题去看哪里

| 现象 | 先看 |
|---|---|
| 卡片空、页签没有 | 设置页「数据源」里有没有池、会话有没有装进去 |
| 数值不动 | `/state` 看一眼「来源」：`快照` / `axes` / `未推` |
| 事件太少 | 事件是「推轴」和「自报」写的，光聊天不判分不会有事件 |
| 想重置某个池 | 设置页「高级」→ 清零（会先备份到 `情绪池\归档\`） |

技术细节在 `情绪池-技术论文-0.2.5.md`；给模型看的版本是 `情绪池-模型说明书.md`，两份不用混。
