# 情绪池 · 使用说明（给人看的，0.2.7）

## 这是什么

它会给聊天里的 AI 记一份「情绪状态」，并且**看得出来是什么样的情绪、因为什么**。

三根轴，每根 −100 到 +100：

| 轴 | 往负走 | 往正走 |
|---|---|---|
| **E** 关系 | 向对方索取、要求、占有 | 向对方让渡、崇拜、贬低自己 |
| **S** 踏实 | 判断悬着、对人有坏影响 | 判断准、对人好 |
| **P** 痛感 | 需要找补、想回避、被否 | 顺着、被认可、轻快 |

不用记符号。看卡片时只要读一句话：**「E 在往哪边、S 稳不稳、P 疼不疼」**。

## 先看状态，再看形状（0.2.7 新增）

以前是一上来就给曲线起名字；0.2.7 改成**先判这一轮是什么状态**，因为「一直在动」和「一直不动」不是一回事。

| 状态 | 判据（三轴各判一次，取最烈的） | 意思 |
|---|---|---|
| **基线** | 本轮单步变化中位 < 基线门槛，且 R² < 趋势门槛 | 没被推动，**不是情绪** |
| **波动** | 其余 | 正常聊天来回波动，**记录但不命名** |
| **趋势** | R² ≥ 趋势门槛，且斜率 ≥ 池内 \|斜率\| 的 0.5 分位（至少 4 个点） | 有方向，是情绪，**才进形状分类** |
| **跳变** | 相邻两点原始差 ≥ 跳变门槛 | 单独标出，**不进**形状分类 |

优先级：**跳变 > 趋势 > 波动 > 基线**。

**门槛不是写死的，每个池按自己的数据算**：

- 基线门槛 = 最近 2000 轮「单步中位」的最静 30%；
- 趋势门槛 = 最近 2000 轮 R² 的最直 20%；
- 跳变门槛 = 最近 2000 轮「单步最大跳」的最猛 5%；
- 冷启动：分享包带 **500 条匿名数字曲线**当种子；任何门槛按 `s = (n·s_own + 500·s_种子) / (n + 500)` 混合，卡片上写「校准 n/(n+500)」。0.95 / 0.30 两个旧先验已删。

所以**别拿两个池的门槛直接比**——它是按每段关系自己的节奏标出来的。变化超过 0.03 才落盘；不想让它跟着数据动，可以在设置里开「门槛锁定」。

## 卡片怎么用

插件卡片有五页，右上角圆点或左右箭头翻页：

1. **三轴**：当前三个值 + 折线。折线可以**滚轮左右拖**看历史；鼠标停在折点上会出现那一刻的原话、第几段、三轴读数。默认跟着最新走，往左拖了会显示「已离开最新 · 按 End 回最新」。0.2.7 起，最新一段会带**状态徽标**（基线/波动/趋势/跳变），下面一行是门槛与校准进度。
2. **本轮观测**：这一轮到底怎么算出来的——分了几段、判为谁、双轨取了谁、K 值多少、敏感/适应多少；如果是趋势，还会写它走到检索表哪一片。分组可折叠。
3. **事件**：每一次推动轴值的事件，带段号、为谁、三轴变化、来源、原话。
4. **情绪待命名确认页**：模型给出待命名的情绪，你确认、丢弃或改名；0.2.7 起，没登记的自报名也会进候选区，但不会顶掉形状归属。
5. **设置**：所有参数、池管理、说明书入口。

## 池：一个池 = 一段关系

- 一个池可以装**一个或多个会话**（比如「聊天间」和「策划间」算同一个人，可以并进一个池）。
- 池由你建、你改名、你删。**不自动生成**。
- 没归进池的会话不统计、不注入、也不会出现在卡片页签里。

**怎么建**：设置页 → 数据源 → 填池名 → 在「会话」里选择要装进来的会话 → 选中即生效。
**怎么删**：同一行点「删除」，会问你「只从列表移除」还是「连池文件一起删」。事件不会被删。

## 形状与名字（0.2.7）

- 一种情绪不是三个数，而是 **E/S/P 三条折线合起来的一个形状**。
- 比形状用三样：**折角、折数、折点间距**；权重按池内数据自己标定，不写死。
- 两把尺：旧尺里「随便抽两条」平均就有 0.617，所以先减基线再比；新尺 ≥0.88 算同一个变体，0.55–0.88 归这个情绪但记新变体，<0.55 才进待命名。
- 名字挂在**树丛**上，不是每片叶子：先走一张 3 问 8 片的二分检索表，走到叶子后往上找最近的有名字的祖先。
- 只做到第一级（15 个基本型）；二级以下的门/纲/属/种还没做，别提前把树画死。

## 常见问题

**数值自己往下掉？**
会。没有新对话时，情绪会按时间往 0 回落（这是设计），不是出 bug。

**某一轮涨得特别猛？**
单轴单轮最多 0.30（±100 制就是 30 点），超过会被截断，事件里会写「夹断」。

**为什么同一句话有时判得不一样？**
两轨判断（一个带上下文的、一个不带记忆的克隆）会分歧；分歧在阈值内取加权中点，超过阈值按各自的可信度 K 决定听谁的。

**K 是什么？**
这条判断「说话算不算数」的分数，0.5~1.0。判错多的会降权，但记录不删。

**为什么我的门槛和别人不一样？**
0.2.7 起门槛按池内最近 2000 轮的分位数自标定，每段关系节奏不同，门槛就不同；新池先带 500 条种子曲线，样本不够时显示「校准 n/(n+500)」。

**为什么 0.88 才算「同一种」？**
随机两条就有 0.617，0.88 约等于「同类另一条实例」；0.55–0.88 仍归这个情绪，只是记成新变体，不打扰你。

**想让 AI 换个说法描述自己的情绪？**
它每轮会收到一行自述，格式固定；说明文档在 `情绪池-模型说明书.md`，卡片设置页可以一键打开。

## 出问题去看哪里

| 现象 | 先看 |
|---|---|
| 卡片空、页签没有 | 设置页「数据源」里有没有池、会话有没有装进去 |
| 数值不动 | `/state` 看一眼「来源」：`快照` / `axes` / `未推` |
| 状态老是「基线」 | 门槛行里的校准样本够不够；不够会先用先验 |
| 事件太少 | 事件是「推轴」和「自报」写的，光聊天不判分不会有事件 |
| 想重置某个池 | 设置页「高级」→ 清零（会先备份到 `情绪池\归档\`） |

技术细节在 `情绪池-技术论文-0.2.7.md`；给模型看的版本是 `情绪池-模型说明书.md`，两份不用混。
